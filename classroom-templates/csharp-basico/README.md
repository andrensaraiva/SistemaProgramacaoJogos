# Template C# Basico - GitHub Classroom

Use este template para listas fora da plataforma web, com testes automatizados em C#.

## Como usar

1. Crie um repositorio template no GitHub com esta pasta.
2. No GitHub Classroom, crie uma assignment usando esse template.
3. O aluno adapta `src/Quest.cs` para o desafio da atividade.
4. O GitHub Actions roda `dotnet test`.

## Comandos locais

```powershell
dotnet test
```
