# Manual rapido do professor

## Turmas

- Crie turmas em `/turmas/nova`.
- Compartilhe o codigo de convite com alunos.
- Acompanhe membros, listas e ranking dentro da turma.

## Exercicios

- Use `/exercicios` para ver desafios publicados.
- Use `/exercicios/gerar` para criar exercicios com Gemini.
- Exercicios gerados salvam enunciado, starter code, solucao interna e testes.

## Listas

- Dentro de uma turma, crie uma lista em `Nova lista`.
- A tela da lista mostra progresso por aluno e exercicio.

## Antifraude

A plataforma registra:

- eventos de paste;
- numero de edicoes no editor;
- tempo entre primeira edicao e envio;
- similaridade entre codigos recentes da mesma lista.

Esses sinais aparecem na tela de progresso da lista como alertas. Eles nao sao
prova definitiva: servem para orientar conversa e revisao pedagogica.

## Duelos

- Alunos criam duelos em `/duelos`.
- O desafiante compartilha o codigo.
- O primeiro participante que aprovar o exercicio vence quando o duelo for
atualizado.

## Unity e GitHub Classroom

Use `/unity` para consultar os templates do repositorio:

- `classroom-templates/csharp-basico`
- `classroom-templates/unity-projeto`

Esses templates sao ponto de partida para atividades avaliadas por GitHub
Actions.
